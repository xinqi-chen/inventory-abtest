# Controlled Stochastic Simulation Reproduction

See the [paper results](../README.md#results) for saved figures and summary CSVs.

This folder contains the code needed to reproduce the final controlled stochastic simulation results used for the paper draft. It is separate from the trace-driven FreshRetailNet experiments.

Scenario 1 corresponds to §5.1 / Fig. 2 (downward mean-bias reduction);
Scenario 2 corresponds to §5.1 / Fig. 3 (forecast-error dispersion reduction).
See the [paper-to-experiment map](../docs/experiment_design.md) and
[reproduction guide](../docs/reproduction.md#controlled-experiments).

## Files

- `run_controlled_stochastic.py`: main stochastic uniform-demand simulator.
- `plot_abtest_violins.py`: reproduces the violin figures in the same visual style as `abtest/main_abtest_me.py`.
- `assemble_final_outputs.py`: collects Scenario 1 and Scenario 2 outputs into one final results folder and writes the Markdown report.
- `run_final_experiments.sh`: one-command reproduction script for the final selected settings.
- `requirements.txt`: minimal Python package list.

The simulator uses the historical internal design name `BR`; figures and reports display it as `PR`. This design independently randomizes each item–period cell.

## Final Settings

Scenario 1:

- `N = 3000`, `T = 60`
- capacity factors: `0.90, 0.92, 1.20`
- `Delta_control = -0.5`, `Delta_treat = -0.05`
- parameter mode: `moderate_demand_heterogeneous`
- estimator: `diff_in_means`
- replications: `R_GTE = 300`, `R_DESIGN = 300`

Scenario 2:

- `N = 3000`, `T = 60`
- capacity factors: `0.85, 1.00, 1.10`
- `eta_control = 30.0`, `eta_treat = 0.2`
- parameter mode: `scenario2_clean_signal`
- estimator: `diff_in_means`
- replications: `R_GTE = 300`, `R_DESIGN = 300`

## Reproduce

From the repository root:

```bash
cd controlled_stochastic_simulations
bash run_final_experiments.sh
```

By default, the script uses `python3` from your active environment.

Optional environment variables:

```bash
PYTHON=/path/to/python WORKERS=8 OUT_ROOT=outputs_reproduced bash run_final_experiments.sh
```

If you use a custom Python environment, install the dependencies first:

```bash
python -m pip install -r requirements.txt
```

The final combined outputs will be written to:

```text
controlled_stochastic_simulations/outputs_reproduced/final_theory_verification/
```

The main paper-style plots are PNG files generated by `plot_abtest_violins.py`
and collected in `final_theory_verification/figures_abtest_style/`. The older
ReportLab PDF diagnostics under per-scenario `figures/` folders are optional and
are skipped by `run_final_experiments.sh`.

Main outputs:

- `selected_capacity_regimes_combined.csv`
- `summary_scenario1_full_grid.csv`
- `summary_scenario2_full_grid.csv`
- `raw_estimates_scenario1_selected.csv`
- `raw_estimates_scenario2_selected.csv`
- `figures_abtest_style/*.png`
- `controlled_stochastic_final_report.md`
- `theory_region_warnings_combined.txt`
